# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, accept constructive feedback gracefully, and focus on what's best for the people who use this project. Harassment, insults, personal attacks and publishing other people's private information are not acceptable in issues, pull requests, discussions or anywhere else the project is represented.

## Reporting

If someone's behavior concerns you, contact the maintainer, [@shubham-web](https://github.com/shubham-web), through the contact details on their GitHub profile. Reports are handled privately.

The maintainer may remove comments, commits, code, issues and other contributions that break this code, and may temporarily or permanently ban contributors who do so, as described in the Contributor Covenant's enforcement guidelines.
